# VELTOR stories

Автоматическая сборка Instagram-сторис из постов темы «Мото» в Telegram-группе
@koreamotocycles_veltor по утверждённому шаблону.

- Каждые 15 минут GitHub Actions забирает новые посты через бота, берёт фото
  альбома и 5 строк (модель, год, пробег, цена) и собирает сторис 1080×1920.
- Основной формат — коллаж: компактный блок текста сверху и две карточки со скруглёнными
  углами одна под другой, без наложения (фото чуть ярче и насыщеннее): внизу фото, где мотоцикл виден целиком (из первых трёх фото альбома),
  сверху другое фото этого мотоцикла (другой ракурс); деталь — только если других нет.
  Фото покрышки и почти одинаковые кадры не используются никогда. Что на фото, определяет детектор YOLO11n (`models/`, `detect.py`).
  Пост с одним фото собирается в одиночном формате.
- С 05.11.2026 основной дизайн VELTOR — `story_a2.py`, вариант `s3_price_pill` с белым свечением (с 05.11 13:50; главное фото кадрируется по целому мотоциклу, цена в светлой плашке вместо кнопки)
  (`format_a` в `config.json`; если убрать этот ключ, вернётся прежний коллаж `make_story.py`):
  чёрный фон со светлым свечением в центре, VELTOR слева вверху, высокое главное фото и до трёх
  фото справа, год/пробег, строка из 3+ особенностей из описания поста (`features.py`, всегда в одну строку),
  цена под ключ и кнопка «Узнать подробности». Шрифты Montserrat и Unbounded (OFL).
- Готовые сторис лежат в `stories/`, список — в `queue.json`.
- Фото обрабатываются автоматически: реставрация Real-ESRGAN (`upscale.py`, как в Upscayl;
  включается `restore_photos` в `config.json`), баланс белого и уровни, насыщенность, чёткость,
  резкость и лёгкое притемнение фона вокруг мотоцикла.
- Видео-версия коллажа (`video.py`, MP4 8 с) сейчас выключена: `send_video` в `config.json`.
- Сразу после сборки бот присылает сторис файлом (полное качество 1080×1920)
  в рабочую группу Telegram «Сторисы» (получатели в `config.json`); музыку добавляете
  вручную при публикации в Instagram.

Токен бота хранится в Settings → Secrets and variables → Actions →
`TELEGRAM_BOT_TOKEN` и в репозитории не виден.

Шрифты: Inter (SIL Open Font License) и TeX Gyre Heros (GUST Font License), см. `fonts/`.

## Сторож на сервере (`guard/`)

Постоянно работающий скрипт на VPS под @VELTOR_moderator_bot: удаляет уведомления
«проголосовал(а) за группу» за секунды и сразу запускает сборку сторис, когда в «Мото»
появляется пост. Установка (под root): `curl -fsSL https://raw.githubusercontent.com/suzukicanal-cyber/veltor-stories/main/guard/install.sh | bash`.
Журнал: `journalctl -u veltor-guard -f`.

Рабочий вариант сторожа — Cloudflare Worker `veltor-guard` (`guard/cloudflare-worker.js`,
https://veltor-guard.suzuki-canal.workers.dev), вебхук @VELTOR_moderator_bot. Секреты BOT_TOKEN,
GITHUB_TOKEN, WEBHOOK_SECRET хранятся в настройках Worker. С VPS FirstVDS Telegram недоступен.

## Публикация в сторис группы (кнопка «Опубликовать»)

Под каждой сторис в «Сторисах» бот ставит кнопку. Она открывает Worker (`/publish?id=…&sig=…`,
подпись HMAC ключом `PUBLISH_KEY` = `WEBHOOK_SECRET` воркера), тот запускает `publish.yml`:
`publish.py` делает видео (картинка без движения + мелодия из `music/`, `publish.seconds` секунд)
и публикует его в сторис группы от аккаунта владельца (Telethon). Секреты GitHub: `PUBLISH_KEY`,
`TG_API_ID`, `TG_API_HASH` (my.telegram.org), `TG_SESSION` (создаётся `guard/make_session.py`
на своём компьютере). Без `PUBLISH_KEY` кнопка не показывается.

## Товары ВКонтакте (`vk_market.py`)

После сборки сторис каждый новый пост из «Мото» становится товаром в группе ВК
(`config.json` → `vk_market.group`, сейчас https://vk.ru/moto_liis), подборка «Мотоциклы».
Название — «Модель, год», цена — из поста, до 5 фото (те же, что отобраны для сторис),
в описании год, пробег, цена и строка «Цена актуальна на ДД.ММ.ГГГГ» — дата публикации поста в Telegram,
дальше текст поста. Если модератор перевыложил исправленный пост того же мотоцикла
(модель + год + пробег совпадают), товар не дублируется, а обновляется.

- Секрет GitHub `VK_TOKEN` — ключ доступа с правами «Товары» и «Фотографии». Без него шаг пропускается.
- `since` — с какой даты поста выкладывать (старые посты не трогаются), `per_run` — не больше N товаров за запуск.
- Результат и ошибки — в `queue.json` (`vk_item_id`, `vk_error`); ошибка ВК не мешает сторис.
