# VELTOR stories

Автоматическая сборка Instagram-сторис из постов темы «Мото» в Telegram-группе
@koreamotocycles_veltor по утверждённому шаблону.

- Каждые 15 минут GitHub Actions забирает новые посты через бота, берёт фото
  альбома и 5 строк (модель, год, пробег, цена) и собирает сторис 1080×1920.
- Основной формат — коллаж: компактный блок текста сверху и две карточки со скруглёнными
  углами одна под другой, без наложения (фото чуть ярче и насыщеннее): внизу фото, где мотоцикл виден целиком (из первых трёх фото альбома),
  сверху другое фото этого мотоцикла (другой ракурс); деталь — только если других нет.
  Фото покрышки и почти одинаковые кадры не используются никогда. Что на фото, определяет детектор YOLO11n (`models/`, `detect.py`).
  Пост с одним фото собирается в одиночном формате.
- Готовые сторис лежат в `stories/`, список — в `queue.json`.
- Фото обрабатываются автоматически: реставрация Real-ESRGAN (`upscale.py`, как в Upscayl;
  включается `restore_photos` в `config.json`), баланс белого и уровни, насыщенность, чёткость,
  резкость и лёгкое притемнение фона вокруг мотоцикла.
- К каждому коллажу собирается видео-версия (`video.py`, MP4 8 с): карточки выезжают,
  фото плавно приближаются к мотоциклу. Видео не хранится в репозитории.
- Сразу после сборки бот присылает сторис файлом (полное качество 1080×1920)
  в рабочую группу Telegram «Сторисы» (получатели в `config.json`); музыку добавляете
  вручную при публикации в Instagram.

Токен бота хранится в Settings → Secrets and variables → Actions →
`TELEGRAM_BOT_TOKEN` и в репозитории не виден.
