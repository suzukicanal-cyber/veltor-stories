# Поиск лидов VELTOR в Telegram-чатах

Каждый час GitHub Actions (`.github/workflows/leads.yml`) читает новые сообщения в мото-чатах,
где состоит отдельный аккаунт-**читатель**, и присылает в Telegram карточку на каждого, кто хочет
мотоцикл из Кореи или привезти байк под заказ: в каком чате, кто, что написал, почему это лид,
кнопки «Открыть» (сообщение) и «Профиль», готовый черновик ответа (нажатие копирует текст).

Читатель ничего не пишет и никому не отвечает. Отвечает менеджер с @veltor_kor — лучше прямо в чате,
реплаем на сообщение, своими словами по черновику. Для этого @veltor_kor тоже должен состоять в чате.

## Как отличает покупателя от продавца
Чат и так про мото, поэтому нужны слова про привоз («из Кореи» — больше всего баллов, «из Японии»,
«под заказ», «пригнать», «растаможка») и слова покупателя («хочу», «подскажите», «кто пригонял»,
«сколько выйдет»). Минус — за признаки объявления: «продам», «в наличии», «привезём», «пишите
в личку», телефоны, цены «от …». 🔥 горячий — от 5 баллов, 🟡 тёплый — от 3. Сообщения ботов
и самого @veltor_kor пропускаются. Проверка фильтра: `python leads/test_hunter.py`.

## Запуск (один раз)
1. **Аккаунт-читатель.** Заведите отдельный аккаунт Telegram на запасную SIM. Не @veltor_kor:
   доступ к читателю хранится на GitHub, и если Telegram что-то заподозрит, пострадает только он.
2. **Ключи API.** С аккаунта читателя войдите на my.telegram.org → API development tools,
   создайте приложение (название любое) и скопируйте `api_id` и `api_hash`.
3. **Сессия.** На своём компьютере (с включённым VPN, если Telegram не открывается):
   установите Python с python.org, затем в терминале
   `pip install telethon` и `python tg_login.py` (файл `leads/tg_login.py`).
   Введите api_id, api_hash, номер читателя и код из Telegram — скрипт напечатает длинную строку.
4. **Секреты** в репозитории: Settings → Secrets and variables → Actions → New repository secret:
   `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` (та длинная строка). Никому её не показывайте.
5. **Чаты.** Actions → VELTOR leads → Run workflow → режим `find_chats`: бот пришлёт список
   публичных мото-чатов. Вступите с аккаунта читателя в подходящие (вручную или впишите их
   в `tg_join` — агент вступит сам, по 3 за запуск). Читаются все группы, где состоит читатель.
6. **Проверка:** Run workflow → режим `test` — придёт пример карточки.

Лиды приходят в личку VELTOR_KOR (`deliver_to_chat_ids` в `config.json`). Чтобы видела вся команда:
создайте группу «Лиды», добавьте туда бота — через 15 минут её номер появится в `seen_chats.json`,
впишите его в `deliver_to_chat_ids`.

## Настройки (`config.json`)
| Поле | Что это |
| --- | --- |
| `tg_join` | публичные чаты (`@имя` или ссылка), в которые читатель вступит сам, по `tg_join_per_run` за запуск |
| `tg_ignore_usernames` | чьи сообщения не показывать (свои аккаунты, знакомые продавцы) |
| `tg_find_queries` | слова для поиска чатов в режиме `find_chats` |
| `max_cards_per_run` | сколько карточек за запуск; остальные лиды придут одним списком |
| `min_score`, `hot_score` | пороги «тёплый» и «горячий» |
| `first_run_hours` | за сколько часов смотреть чат, когда агент видит его впервые |
| `vk_*`, `rss_feeds` | необязательные источники: публичные посты ВК (нужен секрет `VK_SERVICE_TOKEN`) и RSS |

## Что хранится
Репозиторий публичный, поэтому в `seen.json` лежат только хэши показанных сообщений и номер
последнего прочитанного сообщения в каждом чате (под хэшем), а в журнал Actions пишутся только
количества. Тексты, имена и ссылки уходят только в Telegram.
